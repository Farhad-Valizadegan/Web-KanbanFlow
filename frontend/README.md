# KanbanFlow

The React and TypeScript frontend for KanbanFlow. The repository and local project folder are named **Web-KanbanFlow**.

See the [project README](../README.md) for complete setup, authentication configuration, features, and release information.

## Development

From the frontend directory, install locked dependencies with `npm ci`, configure `.env` from `.env.example`, and start the application with `npm run dev`.

## Verification

- `npm run lint` checks the frontend source.
- `npm run build` runs TypeScript checks and creates the production build.
- `npm run preview` previews the production build.

The npm package identifier is `kanbanflow`; the product's display name is **KanbanFlow**.
