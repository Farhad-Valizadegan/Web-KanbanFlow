# KanbanFlow v1.2.0 — 2026-10-11

This compatible interface release gives KanbanFlow a skeuomorphic workbench and visible motion while preserving API contracts and owner-only membership permissions.

## Changes

- Add beveled panels, blue enamel buttons, recessed fields and workflow trays, paper-like task cards, and light/dark/system material tokens.
- Redesign shared navigation, home and authentication screens, dashboard cards, and board controls with responsive layouts and consistent SVG icons.
- Add staggered entrances, spring settling, hover lift, button compression, board/form reveals, drag feedback, and native overlay transitions. Respect reduced-motion preferences.
- Show column creation on demand, give task titles more room, and use viewport-level notification popovers with native dismissal.
- Fix pale primary buttons caused by competing neutral styles; remove input-like backgrounds from analytics summaries and empty messages.
- Explain local API/database requirements on session failure and disable repeated retry while checking.
- Align project guidance and diagrams with current version and owner-only membership policy.

## Validation and limits

Frontend production build and ESLint pass; the 10 session-route regression tests pass. Browser checks covered responsive home layouts, both themes, animation timings, and prior preview checks of form validation, password visibility, notifications, and board controls. Protected workflow previews used isolated data; this does not establish a live MySQL end-to-end test. Backend code is unchanged and its suite was not rerun for this presentation release.

## Upgrade

No dependency updates, migrations, or API changes. Rebuild/restart the frontend. Local authentication requires the API and MySQL to be running. The v1.2.0 annotated source tag identifies this release; a GitHub Release page and production deployment are separate operations.
